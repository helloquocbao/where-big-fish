# Backend

Server game (room instance, matchmaking, game loop, luật va chạm/nhảy đè, bomb spawn/targeting/
timer, drop hạt năng lượng khi chết).

Là nguồn authoritative cho mọi luật chơi. Khi đổi giá trị trong `../shared/`, backend đề xuất
trước (xem `../AGENTS.md`). Xem `../docs/concept_brief.md` cho spec đầy đủ.
